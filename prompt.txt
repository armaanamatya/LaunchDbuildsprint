Build a graph-based agentic coding interface that replaces chat-based workflows with a visual branching system.

Core concept:

* Each node represents a git worktree (branch) with an associated coding agent.
* Nodes form a directed graph where edges represent branch derivation (parent → child).
* Multiple nodes can run in parallel, each executing tasks independently.

Key features:

1. Worktree-backed execution:

   * Each node operates in an isolated git worktree.
   * Agents can plan, edit, run, and test code within that workspace.

2. Multi-agent support:

   * Allow selecting and switching models (e.g. Claude, GPT) per node.
   * Support running multiple agents simultaneously across nodes.

3. Diff-first interface:

   * Display only git diffs between base and current branch by default.
   * Allow expanding into full code view when needed.

4. Graph UI:

   * Visualize nodes and edges (branch relationships).
   * Show node metadata: status, agent type, diff summary, test results.

5. Evaluation layer:

   * Automatically evaluate each node using tests, linting, and optional scoring.
   * Surface best-performing branches.

6. Merge & decision workflow:

   * Allow users to compare nodes and merge selected branches into main.
   * Handle merge conflicts visually.

7. Observability:

   * Store agent traces (steps taken, reasoning, commands run).
   * Allow replay/debug of agent actions.

8. Resource management:

   * Queue, pause, resume, or kill nodes.
   * Track compute usage per node.

Goal:
Enable developers to explore multiple implementation paths in parallel and make decisions based on structured comparisons rather than linear chat interactions.
